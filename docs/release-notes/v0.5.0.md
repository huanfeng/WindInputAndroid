# 清风输入法 Android v0.5.0

距上一版 v0.2.0 的大版本更新：键盘、候选、联想、设置几乎全部重做，补齐了日常打字需要的大部分功能。

> 这是预览版。遇到问题请在「设置 → 关于 → 反馈问题」提交，附上「分享诊断信息」更好排查。

## 安装与升级

- 从 GitHub Release 或官网下载页取 APK，直接覆盖安装即可，设置和词库都保留。
- 输入法不联网，不会自己检查更新。新版本请留意 GitHub Release 或官网。
- 只提供 64 位（arm64-v8a）安装包。

## 出厂设置变化

- 默认方案改为**全拼**；首次使用会弹出方案选择，可改选五笔、双拼等。
- 「123」默认进九宫格数字键盘。

## 键盘

- 字母键盘按大众布局重排，数字与符号角标、逗号句号各占一键；上滑输入符号，长按气泡为「大写 | 符号 | 小写」。
- 123 层、分类符号页、九宫格数字键盘；九宫格左侧符号栏可滑动，列表可在设置里自定义。
- **键盘选择**：工具栏新增键盘图标，按方案分格（拼音、五笔、双拼、清风英文、英文直输等），点一下即切。
- **工具栏**：可常驻剪贴板、文本编辑、表情、语音等入口，在「编辑工具栏」里拖动排序、增删。
- **退格手势**：上滑清空输入框，下滑恢复刚删掉的内容。
- 单手模式、键盘边距（底部留空、左右留边）、键盘行高与候选字号可调。
- 振动强度可调；多指快打不再丢键。
- 支持外接实体键盘。
- 读屏（TalkBack）可逐键朗读。

## 候选与输入

- 候选后显示编码提示（五笔剩余编码、拼音反查码）；长按候选查看编码、读音、释义、五笔字根拆分。
- 候选长按菜单：置顶、移动、删除、恢复默认、复制。
- 拼音整句语法模型（默认开）、拼写纠错、误读提示、模糊音（按声母 / 韵母勾选）。
- 拼音输入时可点音节栏修正中间的拼音。
- **智能联想**：上屏后给下一个词，并会参考光标前的文字。
- **英文**：补全、自动空格、句首大写、双击空格出句号。
- **快捷输入**（工具栏闪电图标）：计算、数字转金额大写、日期等；候选来源可开关、排序。
- 临时拼音、快捷短语、Emoji 候选与附加符号模块、简繁转换。
- **无痕**：密码框与私密输入框不学习，也可在快捷面板手动开启。

## 设置与词库

- 设置页全新设计，按「键盘 / 输入 / 词库 / 高级」分组。
- 系统输入法列表里显示当前方案，切换方案时同步。
- 方案管理：导入方案包（.wpkg / .zip，可从文件管理器直接打开），删除或恢复自带方案，每个方案有自己的设置页。
- 词库：查看、搜索、添加、删除个人词；导出 / 导入词库，与电脑版互通；词库统计。
- 输入统计：每天打字数。
- 「高级」里可分别恢复键盘设置和输入设置的默认值，不动词库。

## 隐私

- 不申请网络权限，输入内容不会离开手机。
- 设置与个人词库会随系统备份（如果你开了系统备份），剪贴板历史不进备份。
- 完整说明见「设置 → 关于 → 隐私政策」或 https://windinput.com/privacy
