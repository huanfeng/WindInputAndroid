# 清风输入法 Android v0.5.2

v0.5.1 的修复版：修 Android 13 及以下的闪退，并补强问题反馈的诊断信息。

> 这是预览版。遇到问题请在「设置 → 关于 → 反馈问题」提交，附上「导出诊断压缩包」更好排查。

## 安装与升级

- 从 GitHub Release 或官网下载页自动附上的校验信息核对后覆盖安装即可，设置和词库都保留。
- 输入法不联网，不会自己检查更新。新版本请留意 GitHub Release 或官网。
- 只提供 64 位（arm64-v8a）安装包。

## 修复

- **Android 13 及以下闪退**：按方案注册系统输入法子类型用到的接口要 Android 14 才有，低版本一同步方案就崩。现在只在 Android 14+ 注册，低版本保留原来的单一子类型。

## 改进

- **导出诊断压缩包**（设置 → 关于）：打成 zip，含更长的日志（包括崩溃前那次运行）和系统崩溃缓冲，之前重启后只能看到新进程的日志。同样不含你输入的文字。
- **诊断信息新增界面段**：记录键盘底部避让相关的系统数值（导航模式、各类 insets），用于排查「键盘下方空白」这类问题。
