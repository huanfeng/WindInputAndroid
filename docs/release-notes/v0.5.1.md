# 清风输入法 Android v0.5.1

v0.5.0 的第一个修复版：修一个打字时容易撞上的问题。

> 这是预览版。遇到问题请在「设置 → 关于 → 反馈问题」提交，附上「分享诊断信息」更好排查。

## 安装与升级

- 从 GitHub Release 或官网下载页自动附上的校验信息核对后覆盖安装即可，设置和词库都保留。
- 输入法不联网，不会自己检查更新。新版本请留意 GitHub Release 或官网。
- 只提供 64 位（arm64-v8a）安装包。

## 修复

- **组码中打 `-` 候选整条消失**：触屏键盘的 `-`（上滑或 123 层打出）不再被当成翻页键收进编码。组码中按 `-`，当前首选先上屏，`-` 作为普通符号接在后面；空闲时打 `-` 行为不变。外接键盘的 PageUp/PageDown 翻页照旧。
