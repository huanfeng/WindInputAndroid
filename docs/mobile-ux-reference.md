# 手机输入法操作习惯与设置架构参考

> 2026-10-15，在模拟器上实拍豆包输入法 1.5.1（基础模式）和微信输入法 4.0.0。
> 截图存在 `ref/ime-compare-2026-10-15/`。键盘布局的对照见 [android-ime-features.md](android-ime-features.md) §14，
> 本文只讲布局以外的操作：功能入口、切方案、表情、设置。
> 结论分两部分：§1–§4 是两家的实际做法，§5–§6 是给我们的设计建议。§6 的设置结构还参照了电脑版和 fcitx5-android，以电脑版为主。

## 1. 功能入口：工具栏 → 功能面板

| 项 | 微信 | 豆包 |
|---|---|---|
| 空闲时的工具栏 | 左边一个品牌图标，右边一个收起按钮；用过的功能会自动出现在中间（「最近使用」位） | 左边一个入口图标，中间一个「点击说话」，右边收起 |
| 点击入口 | 键盘区整个换成**功能面板**：4×2 的大图标格子，可左右翻页（3 页） | 同样是 4×2 格子，2 页 |
| 面板顶栏 | 左边 `^` 返回键盘；右边是「隔空传送」和设置图标 | 左边 `<` 返回；右边是账号/设置图标 |
| 面板内容（按顺序） | 语音转文字、表情、键盘选择、剪贴板、常用语、手写找字、定制工具栏、边写边译、繁体输入、键盘调节、单手模式、悬浮键盘… | 语音输入、表情、键盘选择、智能整理、常用语、剪切板、定制工具栏、手写找字、翻译、繁体输入、键盘调节、单手模式、更多设置、帮助与反馈 |
| 定制工具栏 | 进入编辑态：上面是工具栏当前内容（带 ⊖ 删除），下面是所有工具（点击加入） | 有同名入口 |

**共同点**：
- 键盘上方平时几乎是空的，**所有功能收进一个入口面板**。
- 面板是**整块替换键盘区**的大格子，不是弹窗或小菜单。
- 用户可以定制哪些功能常驻工具栏。
- 「设置」不占格子，放在面板顶栏右上角。

## 2. 切换方案（两家叫「键盘」）

两家都把输入方案叫作「**键盘**」：九宫格拼音、全键盘拼音、手写、笔画、五笔、双拼。用户不需要知道「方案」这个词。

| 入口 | 微信 | 豆包 |
|---|---|---|
| 第一次弹出键盘 | 先让用户选「你喜欢的中文键盘」（6 个大图标） | 同样先选「键盘类型」 |
| 功能面板里的「键盘选择」 | 6 个大图标格子，当前那个高亮；最后一格是「键盘管理」，跳到设置 | 同 |
| **长按中英键** | 弹出一个小气泡：`英 英文` · `中 全键盘`（当前，高亮）· `⚙ 设置`。气泡里放哪些键盘可以在设置里选（「键盘切换键」） | 未实测 |
| 长按 `123` | 弹出 `九宫格` / `全键盘` 两个图标，切换数字键盘的形态 | 未实测 |
| 单击中英键 | 只在「当前中文键盘」和「英文」之间切换 | 同 |

**每个键盘有自己的设置页**（微信）：设置 → 键盘管理 → 五笔键盘「查看详情」：
- 选择五笔方案：86 / 98 / 新世纪。
- 五笔设置：五笔拼音混输、四码唯一直接上屏、第五码将首选词上屏、五笔编码提示。

也就是说，**方案专属的设置挂在方案下面**，不放在全局设置里。

## 3. 表情

- 入口有三处：功能面板「表情」格子、`123` 层底栏的 😊（微信），以及可选的「键盘上显示表情键」开关（两家设置里都有，默认关）。
- 面板布局：
  - 顶部一行：当前分类名，右边「定制表情」和「显示表情键」开关。
  - 中间是表情网格，**横向翻页**。
  - 底部一行：左边 `←` 返回（强调色），中间是横排分类图标（颜文字/贴纸、笑脸、动物、食物、运动、符号、旗帜），右边 `⌫`。
- 和符号页同一套结构：**底部横排分类 + 左返回 + 右删除**。

### 4.3 两家的共同做法

1. **最多两层**（方案详情、模糊音算第三层，属于少数）。首页一眼能看到所有分类，每个分类都有一行**摘要**，写清里面有什么。
2. **按用户的意图分组**，不按程序模块分组：外观 / 按键手感 / 打字习惯 / 键盘（方案）/ 剪贴板 / 隐私。
3. **能看图就不用文字**：候选字号带实时预览；编码显示位置、键盘布局变体都用**缩略图单选卡片**。
4. **选项少而具体**：一个开关对应一个看得见的行为（「双击空格输入句号」），没有「阈值」「权重」「策略」这类工程词。
5. 方案专属设置放在方案详情里；**模糊拼音**因为用得多，单独提到一级。
6. 隐私相关的东西（清空个人词典、离线模式）有独立分组。

## 5. 给我们的建议：键盘内的操作

| 项 | 我们现在 | 建议 |
|---|---|---|
| 工具栏 | 常驻 6 个图标（快捷面板、表情、剪贴板、光标编辑、设置、收起） | 空闲时只放「入口」和「收起」，中间留一个「最近使用」位。其余功能都进功能面板 |
| 功能面板 | 长按中英键打开的快捷面板：方案分段行 + 4 列开关格子 | 改成**点工具栏入口打开、整块替换键盘区**的 4×2 大格子，可以翻页。内容：表情、切换方案、剪贴板、光标编辑、常用语（以后）、简繁、全半角、中英标点、定制工具栏、键盘调节、单手模式（以后）。设置放在顶栏右上角 |
| 切方案 | 快捷面板里的方案分段行 | 两处入口：①功能面板里的「切换方案」（大格子，当前高亮，末尾是「管理」）；②**长按中英键弹出小气泡**：英文 · 已启用的中文方案 · ⚙ 设置。单击中英键只在当前中文方案和英文之间切换 |
| 用词 | 「方案」 | **保留「方案」，和电脑版一致**（见 §6.2）。键盘里的切换气泡、首启选择只显示方案名（五笔 86、全拼、小鹤双拼），不出现「方案」二字，所以不会给新用户添堵。不跟两家改叫「键盘」：我们的「键盘」一词留给安卓专属的那组设置 |
| 表情 | 底栏 ☺ 键 → 表情面板 | 底栏去掉 ☺（见 §14.1）；入口改为功能面板、`123` 层底栏、可选的「键盘上显示表情键」开关。面板结构和符号页统一：底部横排分类，左 `←` 右 `⌫` |
| 首次弹出 | 直接是 26 键 | 先问「选择你常用的输入方式」：五笔 / 拼音 / 双拼 / 英文…（只列我们有的），选完再显示键盘 |

## 6. 给我们的建议：设置架构

### 6.1 现状的问题

- **只有一页**，按程序模块分了 4 组（键盘 / 外观 / 手势 / 候选与剪贴板）。方案选择和双拼布局摊在最上面，十几种双拼布局全部列开。
- **没有任何引擎设置**：13 项全是 K 侧的 `ui.android.*`。PC 端注册表有 320 个配置键，其中码表上屏、调频、模糊音、联想、标点、简繁、英文等大块对手机同样有意义，一个都没接进来。
- 用的是工程词（「键高 dp」「长按判定时长 ms」「编码嵌入输入框」）。

### 6.2 设计约束：三个参照系，各取一样

| 参照 | 取什么 | 不取什么 |
|---|---|---|
| **我们的电脑版**（`wind-setting`） | 一级分类的名字和顺序、卡片（section）名、共用项的标题写法。多端用户在两边找同一个开关，路径应该一样 | 桌面专属项，以及「一页十几张卡」的密度 |
| **fcitx5-android**（`ui/main/MainFragment.kt`） | 首页分两段：「Fcitx」段原样对应桌面 fcitx5 的配置（全局选项 / 输入法 / 附加组件），「Android」段放触屏才有的东西（主题、虚拟键盘、候选窗、剪贴板、表情和符号、插件、高级）。**跨端共用的和本平台独有的分开放** | 它的分类按程序模块分，「附加组件」这种名字用户看不懂 |
| **豆包 / 微信**（§4） | 两层为主、每项一行摘要、缩略图选项、按用户意图归类手机专属项 | 一级分类的名字和整体结构，不照搬任何一家 |

电脑版现在的一级分类：**方案 · 输入 · 按键 · 外观 · 统计 · 词库 · 高级 · 关于**（`wind-setting/src/pages/mod.rs:53`）。
其中「方案」页分两层：
- 按方案类型设的全局值：方案列表，加四张卡（码表 / 拼音 / 混输 / 英文），再加主方案设置、临时拼音、临时英文。
- 单个方案的细节覆盖：在全局值之上，给某一个方案另设一份。这一层太细，**本期手机端不做**，只做按类型的全局值。
「按键」页几乎全是物理键盘和热键，手机上用不到。

### 6.3 建议的结构

首页分三段。第一段与电脑版同名同序，第二段是安卓专属，第三段是收尾。

```
设置首页（每项一行摘要）
│
├─ [状态卡] 没启用或没切换时显示两步引导；已启用时显示「试一试」，进测试台
│
├─ ── 与电脑版相同 ──────────────────────────────
│
├─ 方案 ················· 摘要：当前方案 · 已启用 N 个
│  ├─ 输入方案：启用、排序、默认方案，双拼布局在这里选（长按中英键的气泡里显示这些）
│  ├─ 码表 ············· 对应电脑版「上屏行为」卡：四码唯一自动上屏 · 顶码上屏 · 空码处理 · 编码提示
│  ├─ 拼音 ············· 对应「候选行为」卡：简拼 · 补全 · 调频 · 双拼时允许全拼
│  │   └─ 模糊音 ······· 总开关和各对开关，与电脑版是同一个入口位置
│  ├─ 混输 ············· 对应「混输行为」卡
│  ├─ 英文 ············· 对应「英文行为」卡，加上手机才有的：首字母自动大写 · 双击空格句号 · 选词后加空格
│  └─ 临时拼音 · 临时英文
│  （每张卡底部有「进阶」折叠区，放调频半衰期、保护前 N 位这类工程参数）
│
├─ 输入 ················· 摘要：标点 · 联想 · 简繁
│  ├─ 默认状态：初始语言模式 · 初始字符宽度 · 初始标点模式 · 记忆前次状态
│  ├─ 字符与标点 · 标点配对
│  ├─ 联想输入（写 mobile.association.*，不动电脑版的值）
│  ├─ 简繁转换
│  └─ Emoji（打字时推荐 Emoji）
│
├─ 外观 ················· 摘要：主题名 · 深浅色
│  ├─ 主题（共用 ui.theme.*，电脑版换主题，手机上也跟着换）
│  └─ 候选字体：字号用滑块，旁边实时预览
│
├─ 统计 ················· 摘要：今日 N 字 · 平均速度
│  ├─ 概览：今日 / 本周字数 · 打字速度 · 各方案占比 · 每日字数日历
│  └─ 开启统计 · 统计英文 · 清空统计（与电脑版同一组键：stats.enabled、stats.track_english）
│
├─ 词库 ················· 摘要：个人词 N 条
│  ├─ 个人词库：查看 / 删除 / 清空 · 自定义短语
│  ├─ 备份与恢复 · 从电脑版导入
│  └─ 隐私：暂停学习 · 清空学习数据
│
├─ ── 手机键盘（安卓专属）──────────────────────
│
├─ 键盘布局 ············· 摘要：26 键 · 高度
│  ├─ 键盘高度：拖动调节，竖屏和横屏分开记
│  ├─ 编码显示位置：候选栏上方 / 输入框里（两张预览图）
│  ├─ 逗号句号：合一 / 分开（缩略图）
│  ├─ 字母上滑：数字和符号 / 仅数字 / 关；是否显示角标
│  └─ 显示表情键 · 123 键打开全键盘数字还是九宫格
│
├─ 按键与手势 ··········· 摘要：振动 · 声音
│  ├─ 振动强度 · 按键声音 · 按键气泡
│  ├─ 长按速度：快 / 中 / 慢
│  └─ 空格左右滑移动光标 · 退格左滑批量删除
│
├─ 工具栏与剪贴板 ······· 摘要：工具栏放了哪几个
│  ├─ 定制工具栏和功能面板
│  └─ 复制后在候选栏提示粘贴 · 剪贴板历史
│
├─ ── ─────────────────────────────────────────
├─ 高级 ················· 日志级别 · 外接键盘 · 恢复默认设置
└─ 关于 ················· 版本 · 开源许可 · 反馈
```

几个取舍的理由：

- **「方案」不改名**。电脑版用户一眼就认得；没用过电脑版的用户只会在设置页看到这个词，在键盘上看到的只是方案名（§5）。
- **方案页只做按类型的四张卡，不做每个方案的详情页**。电脑版有单个方案的细节覆盖，但太细，本期不做。以后要做时，照电脑版的形式在卡片里加覆盖入口，不另起一套页面。
- **模糊音放在「拼音」下面一层**，不提到一级。和电脑版的入口位置一样，比照搬两家「提到一级」更重要。
- **电脑版的「按键」一类不出现**。热键和物理键在手机上没用，外接键盘的少数几项放「高级」。「统计」保留，位置和电脑版一样，排在「外观」和「词库」之间。
- **两家的「按键手感」「打字习惯」这类分类名不用**。手机专属的那段用我们自己的名字，内容按用户意图归类，这一点和两家一致。

### 6.4 取舍规则

1. **桌面专属的不进**：热键、浮窗位置和尺寸、托盘、任务栏图标、语言栏、悬停提示、状态气泡、小键盘、Alt 上屏、`candidate_layout` 等，按盘点表里标 ✗ 的一律不显示。
2. **共用项和电脑版写法一致**：卡片名照用电脑版清单的 `section`，项目标题照用电脑版的 `label`。电脑版标题偏工程味的，两边一起改，不在手机上另起一个名字。这样搜索、帮助文档、用户之间口头指路都只需一套说法。
3. **工程参数藏进「进阶」**：调频半衰期、保护前 N 位、混输权重这类，放在卡片底部的「进阶」折叠区，默认收起。
4. **手机专属项写行为**：标题写看得见的行为，数值项改成档位（快 / 中 / 慢）或滑块加预览，不写毫秒、dp。
5. **桌面已有的同名项共用一个键**：主题走 `ui.theme.*`，不再另建 `ui.android.theme`；联想用移动端覆盖键 `mobile.association.*`，不改桌面的值。
6. **视觉类选项用缩略图卡片**：编码显示位置、逗号句号合一、双拼布局。

### 6.5 实现前提（来自代码盘点）

- `wind-mobile` 已有 `config_snapshot / config_defaults / config_registry / config_set`，以及主题相关接口，但 `rust/wind-android` 一个都没有投影。**先补绑定**，设置页才能写引擎项。
- `config_set` 只写盘，写完要再发 `ReloadConfig`。`ConfigValue` 只支持 Bool / Int / Float / Str / StrList，标点映射这类表格项要专门的编辑器，往后放。
- `ui.android.*` 现在存在 K 侧单独的文件里，引擎看不到。要么在 `wind-config` 注册表里加一个移动端域，要么维持现状只放纯 K 侧的项（键盘高度、振动这类）。建议后者：**引擎项走 `config_set`，纯视图项留在 K 侧**，设置清单里用 `source = "engine" | "android"` 区分。
- 统计：记录在 coordinator 里（`record_commit` 写 `wind_store::stats`），手机上本来就在记，但查询只有 `wind-webdata` 的 `stats.summary` / `stats.daily` / `stats.clear`。要在 `wind-mobile` 开对应接口，再投影到绑定，统计页才有数据。图表用 Compose 自己画，形状照电脑版 `wind-setting/src/pages/stats`。
- 设置清单（`settings_manifest.toml`）需要加 `page` / `section` 层级字段、`advanced` 标记和 `preview` 类型，才能生成上面的结构。
- 共用项的 `page` / `section` / `label` 直接取电脑版清单（`wind-setting/src/assets/settings_manifest.toml` 的 `group` / `section` / `label`），安卓清单只记「要显示哪些键、放进哪一档、是否进阶」。电脑版改名时，用一个检查脚本比对两份清单，有出入就报出来，避免两边慢慢说法不一样。
